# UI Package Agent Guide

## Scope
Shared UI components, hooks, and design tokens.

## Rules
- Components must be reusable across apps and app-agnostic.
- Use Tailwind and shadcn/ui patterns; ensure accessibility.
- Export new components, hooks, and tokens via `packages/ui/src/index.ts`.

## Touchpoints
- Source: `packages/ui/src`

## Tests
- Component tests live under `packages/ui/src/test`.
