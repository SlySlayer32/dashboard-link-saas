# Decisions workflow playbook (Folder 8)

This playbook provides step-by-step instructions for `plan/8/NEEDS_DECISIONS.md`.
If a checklist conflicts with this playbook, update the checklist to reference this playbook.

---

## Step 1 - Add a decision

- Write the decision question as a single sentence.
- Add a default suggestion to keep the team moving.
- Keep the scope and impacted folders clear.
- Use the template block in `plan/8/NEEDS_DECISIONS.md`.

Acceptance check:
- The decision is listed under "Open decisions" with a suggestion.

---

## Step 2 - Resolve a decision

- Confirm the final choice with stakeholders.
- Update the relevant plan and playbook for the affected folder.
- Remove the item from the open list once updated.

Acceptance check:
- The plan and playbook reflect the chosen decision.

---

## Step 3 - Keep the list current

- Review the list before starting a new folder.
- Prioritize decisions that block the next execution step.

Acceptance check:
- No open decisions block the current folder in `plan/PLAN_INDEX.md`.
