# CleanConnect Project Brief

## Project Overview
**Name**: CleanConnect  
**Type**: Multi-tenant SaaS platform  
**Purpose**: Workforce management for businesses  
**Founder**: Non-technical user (vibe coding with Cascade/Windsurf)

## Business Model
- B2B SaaS with monthly/annual subscriptions
- Tiered pricing based on company size and features
- Target: Small to medium businesses (10-500 employees)

## Core Value Proposition
Simplify workforce management through:
- Centralized employee data management
- Automated scheduling and time tracking
- Compliance and reporting tools
- Integration with existing HR systems

## Target Market
- Primary: Small to medium businesses
- Industries: Retail, Hospitality, Healthcare, Manufacturing
- Geography: North America (initial launch)

## Competitive Advantages
1. Simple, user-friendly interface
2. Affordable pricing for SMBs
3. Quick setup and onboarding
4. Strong customer support
5. Flexible integrations

## Success Metrics
- Monthly Active Users (MAU)
- Customer retention rate
- Time to onboard new customers
- Customer satisfaction (NPS)

## Current Status
- Phase: Foundation Setup
- Progress: Basic project structure established
- Next: Complete local development environment
- Timeline: Aiming for V1 MVP in 3 months

## Key Decisions Made
1. Tech stack: Hono + Supabase + React + TypeScript
2. Architecture: Zapier-style layering
3. Database: PostgreSQL via Supabase
4. Deployment: Supabase hosting initially
5. Monorepo structure with pnpm workspaces

## Risks and Mitigations
- **Technical complexity**: Using proven stack, following patterns
- **Time to market**: Focused MVP, phased rollout
- **Competition**: Focus on simplicity and support
- **Scaling**: Design for multi-tenant from start
