## Phase 2: Fix Missing Service Imports

### Analysis

Two services are referenced but don't exist:

1. **TokenService** (line 61 in `/dashboard/redeem` endpoint)
   - Used for token validation and dashboard data retrieval
   - Methods: `redeemToken(token)`, `createToken(options)`

2. **SMSService** (line 469 in `/dashboards/:id/send-link` endpoint)
   - Used for SMS job queuing
   - Methods: `enqueueSMS(options)`

### Decision

**Create minimal stub services that return 501 Not Implemented.**

**Rationale**:
- Allows endpoints to exist without runtime errors
- Clear path forward for future implementation
- Maintains API contract for clients
- Better than removing endpoints (which would break clients)

### Implementation

1. **Create TokenService** (`/apps/api/src/services/TokenService.ts`)
2. **Create SMSService** (`/apps/api/src/services/SMSService.ts`)
3. **Add imports to v1.ts**
4. **Update endpoint error handling** to catch and return 501
