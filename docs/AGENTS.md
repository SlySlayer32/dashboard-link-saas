# Docs Agent Guide

## Scope
Architecture and project documentation.

## Rules
- Keep docs aligned with current behavior and architecture.
- When code changes behavior, update docs and phase plans.
- Avoid documenting placeholders as production-ready.

## Touchpoints
- Architecture: `docs/ARCHITECTURE_BLUEPRINT.md`
- Setup: `docs/SETUP_CHECKLIST.md`
- Plans: `plan/PLAN_INDEX.md` (numbered execution order)

## Tests
- No direct tests; validate by building/running apps as needed.
